**Goal:** Add `RJPTSampler`, a true reversible-jump MCMC sampler with parallel tempering for a variable number `k` of copies of one component type plus optional shared parameters, with built-in birth/death, optional component redraw, user-defined within- and between-model moves, storage, checkpoint/resume, tests, docs and an example notebook.

**Architecture:** `RJPTSampler` subclasses `PTSampler` and stores `k` as an extra last column of every row, so swaps, chain files, checkpoints and the MH step are reused unchanged. Rows are NaN-padded to `D = n_shared + K·p` parameters; `RJLayout` owns that convention, `MaskedChainStats` computes adaptive statistics over the active coordinates only, and the RJ moves live in one new module, `impulse/reversible_jump.py`. PTSampler gets two construction hooks and `resume.py` one verification hook; PTSampler chains stay bit-identical.

**Tech Stack:** Python ≥ 3.10, NumPy, SciPy (tests only), pytest, Sphinx + MyST + nbsphinx, nbclient (notebook build), optional JAX.

- Within-model adaptation uses the "Masked full vector" (one NaN-padded history buffer per chain, masked covariance).

Design facts every task relies on:

- A **row** is `(D + 1,)`: `n_shared` shared parameters, `K = max_components` slots of `p = n_component` parameters, then `k`. The active parameters are exactly the prefix of length `n_shared + k·p`; everything after it (up to `D`) is NaN.
- `PTSampler` is constructed with `ndim = D + 1`, so `SamplerState.positions`, `ShortChain` rows, swaps, checkpoints and `chain_stats.current_sample` all carry `k` last. The default temperature ladder therefore uses `1 + sqrt(2 / (D + 1))` as its step (documented in the class docstring; users can pass `temp_step` or `max_temp`).
- `MaskedChainStats` has `ndim = D`: its buffer, `sample_cov` and groups never see the `k` column. RJ moves never use the base `is_full` fast path (it would broadcast a `D`-vector onto a `D + 1` row); they always do `q = row.copy(); q[active_idx] += step`.
- `RJLayout.insert` / `remove` return new arrays and never write to their input (the input is often a view into `SamplerState.positions`).
- User functions are adapted by passing an `_RJCallable` (splits `x[..., :D]` and `k`) into `PTSampler`'s existing `_function_wrapper`, so per-row, vectorized, JAX and threaded evaluation all keep working with no change to the wrapper.

```python
"""PTSampler extension seams used by RJPTSampler."""

import numpy as np
import pytest

from impulse import CheckpointMismatchError, PTSampler


def _lnlike(x):
    return -0.5 * float(np.sum(x**2))


def _lnprior(x):
    return 0.0 if np.all(np.abs(x) < 10) else -np.inf


class _HookedSampler(PTSampler):
    def __init__(self, *args, **kwargs):
        self.calls = []
        super().__init__(*args, **kwargs)

    def _build_chain_stats(self, groups, sample_cov, sample_mean, buffer_size, buffer_thin):
        self.calls.append("chain_stats")
        return super()._build_chain_stats(
            groups, sample_cov, sample_mean, buffer_size, buffer_thin
        )

    def _build_proposal_bundle(self, am_weight, scam_weight, de_weight, de_min_fill):
        self.calls.append(("bundle", am_weight, scam_weight, de_weight, de_min_fill))
        return super()._build_proposal_bundle(am_weight, scam_weight, de_weight, de_min_fill)


def test_build_hooks_are_called_in_order(tmp_path):
    sampler = _HookedSampler(
        ndim=2,
        lnlike=_lnlike,
        lnprior=_lnprior,
        ntemps=2,
        outdir=str(tmp_path),
        am_weight=1,
        scam_weight=2,
        de_weight=3,
        de_min_fill=50,
        verbose=False,
    )
    assert sampler.calls == ["chain_stats", ("bundle", 1, 2, 3, 50)]
    assert sampler.multi_chain_stats.ntemps == 2
    names = [p.__name__ for p in sampler.proposal_bundle.jump_proposals[0].proposal_list]
    assert names == ["am", "scam", "de"]


class _ExtraCheckSampler(PTSampler):
    token = "a"

    def _capture_checkpoint_state(self):
        arrays, meta = super()._capture_checkpoint_state()
        meta["extra_token"] = self.token
        return arrays, meta

    def _verify_extra_metadata(self, meta):
        if meta.get("extra_token") != self.token:
            raise CheckpointMismatchError("extra_token mismatch")


def _extra_kwargs(tmp_path):
    return dict(
        ndim=2,
        lnlike=_lnlike,
        lnprior=_lnprior,
        ntemps=2,
        outdir=str(tmp_path),
        save_freq=50,
        seed=3,
        verbose=False,
    )

    _ExtraCheckSampler(**_extra_kwargs(tmp_path)).sample(np.zeros(2), 120)
    resumed = _ExtraCheckSampler(resume=True, **_extra_kwargs(tmp_path))
    resumed.token = "b"
    with pytest.raises(CheckpointMismatchError, match="extra_token"):
        resumed.sample(np.zeros(2), 200)


def test_verify_extra_metadata_accepts_a_match(tmp_path):
    _ExtraCheckSampler(**_extra_kwargs(tmp_path)).sample(np.zeros(2), 120)
    resumed = _ExtraCheckSampler(resume=True, **_extra_kwargs(tmp_path))
    resumed.sample(np.zeros(2), 200)
    assert resumed.load_chain()["samples"].shape == (2, 200, 2)
```

```python
"""RJLayout: the padded-row convention for reversible-jump states."""

import numpy as np
import pytest

from impulse import RJLayout

L = RJLayout(n_shared=2, n_component=3, max_components=4, min_components=0)


def _row(k, seed=0):
    return L.make_row(np.random.default_rng(seed).normal(size=L.ndim), k)


def test_sizes():
    assert L.ndim == 14 and L.width == 15
    assert L.n_active(0) == 2 and L.n_active(4) == 14
    assert L.slot(1) == slice(5, 8)


def test_make_row_pads_with_nan_and_stores_k():
    row = _row(2)
    assert row.shape == (15,) and row[-1] == 2
    assert np.all(np.isfinite(row[:8])) and np.all(np.isnan(row[8:14]))


def test_make_row_rejects_bad_input():
    with pytest.raises(ValueError, match="k must be an integer"):
        L.make_row(np.zeros(14), 5)
    with pytest.raises(ValueError, match="k must be an integer"):
        L.make_row(np.zeros(14), 1.5)
    with pytest.raises(ValueError, match="shape"):
        L.make_row(np.zeros(13), 1)
    x = np.zeros(14)
    x[3] = np.nan
    with pytest.raises(ValueError, match="finite"):
        L.make_row(x, 1)


def test_active_mask():
    assert L.active_mask(0).tolist() == [True, True] + [False] * 12
    assert L.active_mask(2).sum() == 8
    assert L.active_mask(2) is L.active_mask(2)
    with pytest.raises(ValueError):
        L.active_mask(2)[0] = False
    rows = L.active_mask_rows(np.array([0.0, 2.0, 4.0]))
    assert rows.shape == (3, 14)
    assert np.array_equal(rows[1], L.active_mask(2))


@pytest.mark.parametrize("k", [0, 1, 3])
def test_insert_then_remove_is_identity(k):
    row = _row(k, seed=k)
    u = np.array([7.0, 8.0, 9.0])
    for j in range(k + 1):
        grown = L.insert(row, j, u)
        assert grown[-1] == k + 1
        assert np.array_equal(L.components(grown)[j], u)
        back, removed = L.remove(grown, j)
        assert np.array_equal(back, row, equal_nan=True)
        assert np.array_equal(removed, u)


def test_insert_shifts_later_components():
    row = _row(2)
    before = L.components(row)[:2].copy()
    grown = L.insert(row, 1, [7, 8, 9])
    after = L.components(grown)
    assert np.array_equal(after[0], before[0]) and np.array_equal(after[2], before[1])
    assert np.array_equal(L.shared(grown), L.shared(row))


def test_remove_then_insert_is_identity():
    row = _row(3, seed=5)
    for j in range(3):
        smaller, u = L.remove(row, j)
        assert smaller[-1] == 2 and np.all(np.isnan(L.components(smaller)[2:]))
        assert np.array_equal(L.insert(smaller, j, u), row, equal_nan=True)


def test_insert_and_remove_do_not_mutate_their_input():
    row = _row(2)
    before = row.copy()
    L.insert(row, 0, [1, 2, 3])
    L.remove(row, 1)
    assert np.array_equal(row, before, equal_nan=True)


def test_insert_and_remove_bounds():
    with pytest.raises(ValueError, match="max_components"):
        L.insert(_row(4), 0, [1, 2, 3])
    with pytest.raises(ValueError, match="insert position"):

    assert L.shared(params).shape == (5, 2)
```

```python
The state is ``(k, theta_k)``: ``n_shared`` parameters every model has, then
``k`` components of ``n_component`` parameters each, with
``min_components <= k <= max_components``. It is stored as one padded row of
width ``D + 1``, ``D = n_shared + max_components * n_component``: the shared
parameters, then ``max_components`` component slots (slots past ``k`` hold
NaN), then ``k``. :class:`RJLayout` is the only code that knows this
convention.
"""

from __future__ import annotations

import math
import warnings
from dataclasses import dataclass, field
from typing import Any, Callable, Dict, List, Optional, Tuple

import numpy as np

from impulse.chain_stats import ChainStats, MultiChainStats, _HistoryBuffer, svd_groups
from impulse.proposals import (

@dataclass(frozen=True)
class RJLayout:
    """Slot convention for padded reversible-jump rows.

    A row has ``width = D + 1`` entries: ``n_shared`` shared parameters,
    ``max_components`` slots of ``n_component`` parameters (NaN past ``k``),
    then ``k``. A parameter vector is the same without the trailing ``k``.
    The active parameters at model ``k`` are exactly the first
    ``n_active(k) = n_shared + k * n_component`` entries.

    Components are numbered ``0 .. k - 1``. :meth:`insert` and :meth:`remove`
    shift the later components and update ``k``; both return new arrays and
    never modify their input. Custom moves reach the layout as
    ``chain_stats.layout``.

    Parameters
    ----------
    n_shared : int
        Parameters every model has (noise level, background); may be 0.
    n_component : int
        Parameters per component, at least 1.
    max_components : int
        Largest allowed ``k``, at least 1.
    min_components : int, default 0
        Smallest allowed ``k``.
    """

    n_shared: int
    n_component: int
    max_components: int
    min_components: int = 0
    _masks: Dict[int, np.ndarray] = field(
        default_factory=dict, init=False, repr=False, compare=False
    )

    def __post_init__(self) -> None:
        for name in ("n_shared", "n_component", "max_components", "min_components"):
            value = getattr(self, name)
            if isinstance(value, bool) or float(value) != int(value):
                raise ValueError(f"{name} must be an integer, got {value!r}")
            object.__setattr__(self, name, int(value))
        if self.n_shared < 0:
            raise ValueError(f"n_shared must be >= 0, got {self.n_shared}")
        if self.n_component < 1:
            raise ValueError(f"n_component must be >= 1, got {self.n_component}")
        if self.max_components < 1:
            raise ValueError(f"max_components must be >= 1, got {self.max_components}")
        if not 0 <= self.min_components <= self.max_components:
            raise ValueError(
                "min_components must satisfy 0 <= min_components <= max_components "
                f"({self.max_components}), got {self.min_components}"
            )

    @property
    def ndim(self) -> int:
        """Length ``D`` of the padded parameter vector (without ``k``)."""
        return self.n_shared + self.max_components * self.n_component

    @property
    def width(self) -> int:
        """Length ``D + 1`` of a stored row."""
        return self.ndim + 1

    def n_active(self, k: int) -> int:
        """Number of active parameters at model ``k``."""
        return self.n_shared + int(k) * self.n_component

    def check_k(self, k: Any) -> int:
        """Return ``k`` as an int; ``ValueError`` unless it is a valid model index."""
        kf = float(k)
        if not kf.is_integer() or not self.min_components <= kf <= self.max_components:
            raise ValueError(
                f"k must be an integer in [{self.min_components}, {self.max_components}], "
                f"got {k!r}"
            )
        return int(kf)

    def k(self, row: np.ndarray) -> int:
        """Model index stored in the last entry of ``row``."""
        return int(row[-1])

    def params(self, row: np.ndarray) -> np.ndarray:
        """Padded parameter vector(s): ``row`` without the trailing ``k`` (a view)."""
        return row[..., : self.ndim]

    def shared(self, x: np.ndarray) -> np.ndarray:
        """Shared parameters of row(s) or parameter vector(s) (a view)."""
        return x[..., : self.n_shared]

    def components(self, x: np.ndarray) -> np.ndarray:
        """Component slots of row(s) or parameter vector(s), ``(..., max_components, n_component)``."""
        x = np.asarray(x)
        return x[..., self.n_shared : self.ndim].reshape(
            x.shape[:-1] + (self.max_components, self.n_component)
        )

    def slot(self, j: int) -> slice:
        """Slice of the parameters of component ``j``."""
        start = self.n_shared + int(j) * self.n_component
        return slice(start, start + self.n_component)

    def active_mask(self, k: int) -> np.ndarray:
        """Read-only ``(D,)`` mask of the parameters active at model ``k``."""
        k = int(k)
        mask = self._masks.get(k)
        if mask is None:
            mask = np.arange(self.ndim) < self.n_active(k)
            mask.setflags(write=False)
            self._masks[k] = mask
        return mask

    def active_mask_rows(self, ks: Any) -> np.ndarray:
        """``(n, D)`` mask for a batch of model indices."""
        n_act = self.n_shared + np.asarray(ks).astype(np.intp) * self.n_component
        return np.arange(self.ndim)[None, :] < n_act[:, None]

    def make_row(self, x: Any, k: Any) -> np.ndarray:
        """Build a stored row from a ``(D,)`` parameter vector and ``k``.

        Entries past ``k`` become NaN; the shared parameters and the first
        ``k`` components must be finite.
        """
        k = self.check_k(k)
        x = np.asarray(x, dtype=float)
        if x.shape != (self.ndim,):
            raise ValueError(
                f"expected a parameter vector of shape ({self.ndim},), got {x.shape}"
            )
        n_act = self.n_active(k)
        if not np.all(np.isfinite(x[:n_act])):
            raise ValueError(
                f"the shared parameters and the first k={k} components must be finite"
            )
        row = np.full(self.width, np.nan)
        row[:n_act] = x[:n_act]
        row[-1] = k
        return row

    def insert(self, row: np.ndarray, j: int, u: Any) -> np.ndarray:
        """Copy of ``row`` with component ``u`` inserted at position ``j`` (``0 <= j <= k``)."""
        k = self.k(row)
        p = self.n_component
        if k >= self.max_components:
            raise ValueError(f"cannot insert: k={k} is already max_components")
        if not 0 <= j <= k:
            raise ValueError(f"insert position j={j} must be in [0, {k}]")
        u = np.asarray(u, dtype=float).reshape(-1)
        if u.shape != (p,):
            raise ValueError(f"a component has {p} parameters, got {u.size}")
        row = np.asarray(row, dtype=float)
        out = row.copy()
        lo = self.n_shared + j * p
        hi = self.n_active(k)
        out[lo + p : hi + p] = row[lo:hi]
        out[lo : lo + p] = u
        out[-1] = k + 1
        return out

    def remove(self, row: np.ndarray, j: int) -> Tuple[np.ndarray, np.ndarray]:
        """``(row without component j, the removed component)`` for ``0 <= j < k``."""
        k = self.k(row)
        p = self.n_component
        if not 0 <= j < k:
            raise ValueError(f"remove position j={j} must be in [0, {k - 1}]")
        row = np.asarray(row, dtype=float)
        out = row.copy()
        lo = self.n_shared + j * p
        hi = self.n_active(k)
        u = row[lo : lo + p].copy()
        out[lo : hi - p] = row[lo + p : hi]
        out[hi - p : hi] = np.nan
        out[-1] = k - 1
        return out, u
```

```python
def pairwise_covariance(
    params: np.ndarray, fallback_cov: np.ndarray, min_rows: int
) -> np.ndarray:
    """Pairwise-complete covariance of NaN-padded rows.

    Entry ``(a, b)`` is the sample covariance over the rows where both ``a``
    and ``b`` are present (not NaN); entries with fewer than ``min_rows`` such
    rows take ``fallback_cov[a, b]``. The result is symmetric but not
    necessarily positive semi-definite.
    """
    params = np.asarray(params, dtype=np.float64)
    present = ~np.isnan(params)
    weights = present.astype(np.float64)
    counts = weights.sum(axis=0)
    filled = np.where(present, params, 0.0)
    # Centre each column first: covariance is shift-invariant, and centring
    # avoids cancellation when a parameter's mean is large next to its spread.
    centre = filled.sum(axis=0) / np.maximum(counts, 1.0)
    centred = np.where(present, params - centre, 0.0)
    n_ab = weights.T @ weights
    s_ab = centred.T @ centred
    t_ab = centred.T @ weights  # [a, b]: sum of column a over the rows where b is present
    with np.errstate(divide="ignore", invalid="ignore"):
        cov = (s_ab - t_ab * t_ab.T / n_ab) / (n_ab - 1.0)
    cov = np.where(n_ab >= min_rows, cov, fallback_cov)
    return 0.5 * (cov + cov.T)


def clip_to_psd(cov: np.ndarray, floor: float) -> np.ndarray:
    """``cov`` itself if its smallest eigenvalue is at least ``floor``, else clipped at ``floor``."""
    try:
        w, v = np.linalg.eigh(cov)
    except np.linalg.LinAlgError:
        return cov
    if w[0] >= floor:
        return cov
    fixed = (v * np.maximum(w, floor)) @ v.T
    return 0.5 * (fixed + fixed.T)


def masked_moments(
    params: np.ndarray,
    fallback_mean: np.ndarray,
    fallback_cov: np.ndarray,
    min_rows: int,
    floor: float,
) -> Optional[Tuple[np.ndarray, np.ndarray]]:
    """Per-column mean and repaired pairwise-complete covariance, or None if not finite."""
    params = np.asarray(params, dtype=np.float64)
    present = ~np.isnan(params)
    counts = present.sum(axis=0)
    sums = np.where(present, params, 0.0).sum(axis=0)
    mean = np.where(counts > 0, sums / np.maximum(counts, 1), fallback_mean)
    cov = pairwise_covariance(params, fallback_cov, min_rows)
    if not np.all(np.isfinite(cov)):
        return None
    return mean, clip_to_psd(cov, floor)


@dataclass
class MaskedChainStats(ChainStats):
    """Adaptive statistics over NaN-padded reversible-jump rows.

    ``ndim`` is the padded parameter count ``D``: history rows store the
    parameters with the ``k`` column dropped and NaN in inactive slots. The
    covariance is pairwise-complete over co-active rows
    (:func:`pairwise_covariance`), falls back to the initial covariance for
    pairs seen together fewer than ``min_pair_rows`` times, and is clipped to
    be positive semi-definite. Within-model moves use :meth:`active_block`,
    the factor of the covariance restricted to one group's active coordinates
    at one ``k``; factors are computed on first use and cached until the next
    update, so they cost nothing to checkpoint and rebuild identically.
    """

    layout: Optional[RJLayout] = None
    min_pair_rows: int = 10

    def __post_init__(self) -> None:
        if self.layout is None:
            raise ValueError("MaskedChainStats needs an RJLayout (layout=...)")
        if self.ndim != self.layout.ndim:
            raise ValueError(
                f"ndim={self.ndim} does not match the layout's padded dimension "
                f"{self.layout.ndim}"
            )
        if self.min_pair_rows < 2:
            raise ValueError(f"min_pair_rows must be >= 2, got {self.min_pair_rows}")
        super().__post_init__()
        assert self.sample_cov is not None and self.sample_mean is not None
        self._fallback_cov = np.array(self.sample_cov, dtype=float)
        self._fallback_mean = np.array(self.sample_mean, dtype=float)
        self._factors: Dict[Tuple[int, int], Any] = {}
        self._eligible: Dict[int, List[int]] = {}

    def update_from_window(self, sample_num: int, new_samples: np.ndarray) -> None:
        """Store new ``(n, D + 1)`` rows without ``k`` and recompute the masked moments."""
        layout = self.layout
        assert layout is not None and self.groups is not None
        assert self.svd_U is not None and self.svd_S is not None
        new_samples = np.asarray(new_samples, dtype=float)
        params = new_samples[:, : self.ndim]
        active = layout.active_mask_rows(new_samples[:, self.ndim])
        if not np.all(np.isfinite(params[active])):
            return
        stored = _HistoryBuffer.select_for_storage(params, self._seen_raw, self.buffer_thin)
        self._seen_raw += len(params)
        if len(stored) == 0:
            return
        self.sample_total += len(stored)
        self.update_buffer(stored)
        if sample_num + len(params) < 2:
            return
        n_valid = min(self.sample_total, self.buffer_size)
        moments = masked_moments(
            self._buffer[-n_valid:],
            self._fallback_mean,
            self._fallback_cov,
            self.min_pair_rows,
            self._cov_ridge,
        )
        if moments is None:
            return
        self.sample_mean, self.sample_cov = moments
        self.svd_U, self.svd_S, self.proposal_L = svd_groups(
            self.svd_U,
            self.svd_S,
            self.groups,
            self.sample_cov,
            self.proposal_L,
            ridge=self._cov_ridge,
        )
        self._factors.clear()

    recursive_update = update_from_window

    def set_checkpoint_state(self, arrays: dict, meta: dict) -> None:
        super().set_checkpoint_state(arrays, meta)
        self._factors.clear()
        self._eligible.clear()

    def eligible_groups(self, k: int) -> List[int]:
        """Indices of the groups with at least one coordinate active at model ``k``."""
        cached = self._eligible.get(k)
        if cached is None:
            assert self.layout is not None
            n_act = self.layout.n_active(k)
            cached = [
                gi
                for gi, g in enumerate(self.group_index_arrays())
                if g.size and int(g.min()) < n_act
            ]
            self._eligible[k] = cached
        return cached

    def active_block(self, group_index: int, k: int) -> Any:
        """``(indices, L, n_eff, sqrt(2 n_eff))`` for one group's active coordinates at ``k``.

        ``L`` is the scaled eigen-factor (``L @ L.T`` is the covariance block
        plus the ridge). Returns None when the group has no active coordinate.
        """
        key = (int(group_index), int(k))
        entry = self._factors.get(key, _MISSING)
        if entry is not _MISSING:
            return entry
        assert self.layout is not None and self.sample_cov is not None
        group = self.group_index_arrays()[key[0]]
        idx = group[group < self.layout.n_active(k)]
        if idx.size == 0:
            entry = None
        else:
            block = np.ascontiguousarray(self.sample_cov[np.ix_(idx, idx)])
            _, _, factors = svd_groups(
                [None], [None], [np.arange(idx.size)], block, ridge=self._cov_ridge
            )
            entry = (idx, factors[0], int(idx.size), math.sqrt(2 * idx.size))
        self._factors[key] = entry
        return entry

    def draw_active_block(self, rng: np.random.Generator, k: int) -> Any:
        """Pick a group with active coordinates at ``k``; return its :meth:`active_block` or None."""
        eligible = self.eligible_groups(k)
        if not eligible:
            return None
        return self.active_block(eligible[_draw_group_index(rng, len(eligible))], k)
```

```python
def masked_difference(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """``a - b`` with 0 wherever either entry is NaN (an inactive slot)."""
    d = np.asarray(a, dtype=float) - np.asarray(b, dtype=float)
    return np.where(np.isnan(d), 0.0, d)


def rj_am(chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
    """Adaptive Metropolis on the active coordinates of one group.

    As :func:`impulse.am`, with ``n_eff`` the number of active coordinates in
    the group and the covariance factor of that active block.
    """
    rng = chain_stats.rng
    x = chain_stats.current_sample
    assert x is not None
    block = chain_stats.draw_active_block(rng, int(x[-1]))
    if block is None:
        return x.copy(), 0.0
    idx, factor, neff, sqrt_2neff = block
    scale = _draw_jump_scale(rng)
    q = x.copy()
    q[idx] += 2.4 / sqrt_2neff * scale * (factor @ rng.standard_normal(neff))
    return q, 0.0


def rj_scam(chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
    """Single-component Adaptive Metropolis along one principal axis of the active block."""
    rng = chain_stats.rng
    x = chain_stats.current_sample
    assert x is not None
    block = chain_stats.draw_active_block(rng, int(x[-1]))
    if block is None:
        return x.copy(), 0.0
    idx, factor, neff, _ = block
    scale = _draw_jump_scale(rng)
    ind = rng.integers(0, neff)
    q = x.copy()
    q[idx] += rng.standard_normal() * _SQRT2_INV * scale * factor[:, ind]
    return q, 0.0


class RJDEProposal:
    """Differential evolution on the active coordinates of one group.

    The difference of two stored rows is taken on the group's active
    coordinates, with 0 where either row lacks the slot. Swapping the two rows
    negates the difference with the same mask, so the move is symmetric.
    Returns the current state until ``min_fill`` rows are stored.
    """

    __name__ = "rj_de"

    def __init__(self, min_fill: int = DE_MIN_FILL):
        if min_fill < 2:
            raise ValueError(
                f"min_fill must be >= 2 (two distinct buffer rows are needed for a "
                f"difference move), got {min_fill}"
            )
        self.min_fill = int(min_fill)

    def __call__(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        rng = chain_stats.rng
        x = chain_stats.current_sample
        assert x is not None
        buf = chain_stats._buffer
        n_filled = min(chain_stats.sample_total, len(buf))
        if n_filled < max(self.min_fill, 2):
            return x.copy(), 0.0
        block = chain_stats.draw_active_block(rng, int(x[-1]))
        if block is None:
            return x.copy(), 0.0
        idx, _, _, sqrt_2neff = block
        mm = rng.integers(0, n_filled)
        nn = rng.integers(0, n_filled)
        while mm == nn:
            nn = rng.integers(0, n_filled)
        scale = 1.0 if rng.random() > 0.5 else rng.random() * 2.4 / sqrt_2neff
        offset = len(buf) - n_filled
        q = x.copy()
        q[idx] += scale * masked_difference(buf[offset + mm, idx], buf[offset + nn, idx])
        return q, 0.0


rj_de = RJDEProposal()
```

```python
class IndependentComponentProposal:
    """Component proposal that ignores the current state.

    Parameters
    ----------
    draw : callable
        ``draw(rng) -> u``: one component (``n_component`` values).
    logpdf : callable
        ``logpdf(u) -> float``: the normalized log density of ``draw``'s
        output; finite wherever the component prior is.
    """

    def __init__(self, draw: Callable, logpdf: Callable):
        if not callable(draw) or not callable(logpdf):
            raise TypeError("IndependentComponentProposal needs callable draw and logpdf")
        self._draw = draw
        self._logpdf = logpdf

    def draw(self, rng: np.random.Generator, x: np.ndarray, k: int) -> np.ndarray:
        """One new component; ``x`` and ``k`` are ignored."""
        return self._draw(rng)

    def logpdf(self, u: np.ndarray, x: np.ndarray, k: int) -> float:
        """Log density of component ``u``; ``x`` and ``k`` are ignored."""
        return self._logpdf(u)


def _check_component_proposal(proposal: Any) -> None:
    missing = [name for name in ("draw", "logpdf") if not callable(getattr(proposal, name, None))]
    if missing:
        raise ValueError(
            "component_proposal must have callable draw(rng, x, k) and logpdf(u, x, k); "
            f"{type(proposal).__name__} is missing {missing}"
        )


class BirthDeath:
    """Birth or death of one component: the built-in move between models.

    Birth inserts ``u ~ component_proposal.draw`` at a uniform position;
    death removes a uniformly chosen component. ``b_k = d_k = 1/2`` inside
    the allowed range, ``b_min = d_max = 1``. The map is a slot insertion,
    so the Jacobian is exactly 1. One instance serves every chain.
    """

    __name__ = "birth_death"
    _BRANCHES = ("birth", "death")

    def __init__(self, layout: RJLayout, component_proposal: Any, ntemps: int):
        self.layout = layout
        self.component_proposal = component_proposal
        self._calls = np.zeros((ntemps, 2), dtype=np.int64)
        self._accepts = np.zeros((ntemps, 2), dtype=np.int64)
        self._last_branch = np.full(ntemps, -1, dtype=np.int64)
        self.rejected_deaths = 0

    def _birth_probability(self, k: int) -> float:
        if k >= self.layout.max_components:
            return 0.0
        if k <= self.layout.min_components:
            return 1.0
        return 0.5

    def _log_b(self, k: int) -> float:
        p = self._birth_probability(k)
        return math.log(p) if p > 0.0 else -math.inf

    def _log_d(self, k: int) -> float:
        p = 1.0 - self._birth_probability(k)
        return math.log(p) if p > 0.0 else -math.inf

    def _selection_log_ratio(self, k: int) -> float:
        """``log d_{k+1} - log b_k``: the move-choice term of a birth from ``k``."""
        return self._log_d(k + 1) - self._log_b(k)

    def _choose_death_slot(self, rng: np.random.Generator, k: int) -> int:
        return int(rng.integers(0, k))

    def __call__(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        layout = self.layout
        proposal = self.component_proposal
        rng = chain_stats.rng
        x = chain_stats.current_sample
        assert x is not None
        k = layout.k(x)
        chain = chain_stats.chain_index
        if rng.random() < self._birth_probability(k):
            self._last_branch[chain] = 0
            self._calls[chain, 0] += 1
            j = int(rng.integers(0, k + 1))
            params = layout.params(x)
            u = np.asarray(proposal.draw(rng, params, k), dtype=float)
            log_g = float(proposal.logpdf(u, params, k))
            if not math.isfinite(log_g):
                return x.copy(), -math.inf
            return layout.insert(x, j, u), self._selection_log_ratio(k) - log_g
        self._last_branch[chain] = 1
        self._calls[chain, 1] += 1
        j = self._choose_death_slot(rng, k)
        y, u = layout.remove(x, j)
        log_g = float(proposal.logpdf(u, layout.params(y), k - 1))
        if not math.isfinite(log_g):
            self.rejected_deaths += 1
            return x.copy(), -math.inf
        return y, log_g - self._selection_log_ratio(k - 1)

    def report_branch_accept(self, chain_index: int, accepted: bool) -> None:
        """Count an accepted birth or death for the branch ``chain_index`` last took."""
        branch = int(self._last_branch[chain_index])
        if accepted and branch >= 0:
            self._accepts[chain_index, branch] += 1

    def branch_counts(self, chain_index: int) -> Dict[str, Tuple[int, int]]:
        """``{"birth": (calls, accepts), "death": (calls, accepts)}`` for one chain."""
        return {
            name: (int(self._calls[chain_index, b]), int(self._accepts[chain_index, b]))
            for b, name in enumerate(self._BRANCHES)
        }

    def get_checkpoint_state(self) -> dict:
        return {
            "calls": self._calls.tolist(),
            "accepts": self._accepts.tolist(),
            "last_branch": self._last_branch.tolist(),
            "rejected_deaths": int(self.rejected_deaths),
        }

    def set_checkpoint_state(self, state: dict) -> None:
        self._calls = np.array(state["calls"], dtype=np.int64)
        self._accepts = np.array(state["accepts"], dtype=np.int64)
        self._last_branch = np.array(state["last_branch"], dtype=np.int64)
        self.rejected_deaths = int(state["rejected_deaths"])


class ComponentRedraw:
    """Replace one component with a fresh draw from the component proposal (same ``k``)."""

    __name__ = "component_redraw"

    def __init__(self, layout: RJLayout, component_proposal: Any):
        self.layout = layout
        self.component_proposal = component_proposal

    def __call__(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        layout = self.layout
        proposal = self.component_proposal
        rng = chain_stats.rng
        x = chain_stats.current_sample
        assert x is not None
        k = layout.k(x)
        if k == 0:
            return x.copy(), 0.0
        j = int(rng.integers(0, k))
        rest, old = layout.remove(x, j)
        params = layout.params(rest)
        u = np.asarray(proposal.draw(rng, params, k - 1), dtype=float)
        log_new = float(proposal.logpdf(u, params, k - 1))
        log_old = float(proposal.logpdf(old, params, k - 1))
        if not (math.isfinite(log_new) and math.isfinite(log_old)):
            return x.copy(), -math.inf
        return layout.insert(rest, j, u), log_old - log_new


_FORWARDED_HOOKS = ("get_checkpoint_state", "set_checkpoint_state", "freeze_adaptation")


def _jump_name(move: Any) -> str:
    return str(getattr(move, "__name__", type(move).__name__))


class _WrappedJump:
    """A registered user move: keeps its name and forwards the hooks it has."""

    def __init__(self, move: Callable, layout: RJLayout):
        if not callable(move):
            raise TypeError(f"jump {_jump_name(move)!r} is not callable")
        self.move = move
        self.layout = layout
        self.__name__ = _jump_name(move)
        for hook in _FORWARDED_HOOKS:
            fn = getattr(move, hook, None)
            if callable(fn):
                setattr(self, hook, fn)

    def _result(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        row, qxy = self.move(chain_stats)
        row = np.asarray(row, dtype=float)
        if row.shape != (self.layout.width,):
            raise ValueError(
                f"jump {self.__name__!r} returned a row of shape {row.shape}; expected "
                f"({self.layout.width},): the padded parameters followed by k"
            )
        return row, float(qxy)


class _CheckedWithinModelJump(_WrappedJump):
    """A custom within-model move: must keep ``k`` and leave inactive slots NaN."""

    def __call__(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        row, qxy = self._result(chain_stats)
        x = chain_stats.current_sample
        assert x is not None
        k = self.layout.k(x)
        if row[-1] != k:
            raise ValueError(
                f"within-model jump {self.__name__!r} changed k from {k} to {row[-1]}; "
                "register moves that change k with add_model_jump"
            )
        if not np.all(np.isnan(row[self.layout.n_active(k) : self.layout.ndim])):
            raise ValueError(
                f"within-model jump {self.__name__!r} wrote to an inactive slot "
                f"(entries past k={k} must stay NaN)"
            )
        return row, qxy


class _ModelJump(_WrappedJump):
    """A custom between-model move; the sampler adds ``±log_jacobian`` when ``k`` changes."""

    def __init__(self, move: Callable, layout: RJLayout, log_jacobian: float):
        super().__init__(move, layout)
        self.log_jacobian = float(log_jacobian)

    def __call__(self, chain_stats: MaskedChainStats) -> Tuple[np.ndarray, float]:
        row, qxy = self._result(chain_stats)
        layout = self.layout
        x = chain_stats.current_sample
        assert x is not None
        k_old = layout.k(x)
        try:
            k_new = layout.check_k(row[-1])
        except ValueError as err:
            raise ValueError(f"model jump {self.__name__!r} returned an invalid k: {err}") from None
        n_act = layout.n_active(k_new)
        if not np.all(np.isfinite(row[:n_act])):
            raise ValueError(
                f"model jump {self.__name__!r} returned a non-finite value among the active "
                f"parameters at k={k_new}"
            )
        if not np.all(np.isnan(row[n_act : layout.ndim])):
            raise ValueError(
                f"model jump {self.__name__!r} returned values in slots past k={k_new}; "
                "they must be NaN"
            )
        if k_new > k_old:
            qxy += self.log_jacobian
        elif k_new < k_old:
            qxy -= self.log_jacobian
        return row, qxy


class _RJJumpProposals(JumpProposals):

    def report_accept(self, accepted: bool) -> None:

                rate = accepts / calls if calls > 0 else 0.0
                result[name] = {"calls": calls, "accepts": accepts, "rate": rate}
        return result
```

```python
class _RJCallable:
    """Adapt ``f(x, k)`` to engine rows, which carry ``k`` as the last column."""

    def __init__(self, f: Callable, ndim: int, vectorized: bool):
        if not callable(f):
            raise TypeError(f"{f!r} is not callable")
        self.f = f
        self.ndim = int(ndim)
        self.vectorized = bool(vectorized)
        self.__name__ = _jump_name(f)

    def __call__(self, x: np.ndarray, *args: Any, **kwargs: Any) -> Any:
        d = self.ndim
        if self.vectorized:
            return self.f(np.ascontiguousarray(x[:, :d]), x[:, d].astype(np.intp), *args, **kwargs)
        return self.f(x[:d], int(x[d]), *args, **kwargs)


def _merge_periodic(
    layout: RJLayout,
    periodic: Optional[PeriodicSpec],
    component_periodic: Optional[PeriodicSpec],
) -> Optional[PeriodicSpec]:
    merged: PeriodicSpec = {}
    for i, spec in (periodic or {}).items():
        if not 0 <= int(i) < layout.ndim:
            raise ValueError(
                f"periodic index {i} is outside the padded parameter vector 0..{layout.ndim - 1}"
            )
        merged[int(i)] = spec
    for c, spec in (component_periodic or {}).items():
        if not 0 <= int(c) < layout.n_component:
            raise ValueError(
                f"component_periodic index {c} is outside a component's parameters "
                f"0..{layout.n_component - 1}"
            )
        for j in range(layout.max_components):
            i = layout.slot(j).start + int(c)
            if i in merged:
                raise ValueError(
                    f"parameter {i} (component slot {j}, entry {c}) is declared in both "
                    "periodic and component_periodic"
                )
            merged[i] = spec
    return merged or None


class RJPTSampler(PTSampler):
    """Reversible-jump parallel-tempering sampler for a variable number of components.

    Samples ``(k, theta_k)``: ``n_shared`` parameters every model has, plus
    ``k`` components of ``n_component`` parameters each, with
    ``min_components <= k <= max_components``. Moves that change ``k`` are
    accepted with Green's reversible-jump ratio; tempering, swaps, adaptive
    within-model proposals, chain files and checkpoints work as in
    :class:`PTSampler`. See the *Reversible jump* user guide page.

    Parameters
    ----------
    n_shared : int
        Parameters every model has; may be 0.
    n_component : int
        Parameters per component.
    max_components : int
        Largest ``k``. Every row is padded to
        ``D = n_shared + max_components * n_component`` parameters; slots past
        ``k`` hold NaN.
    lnlike, lnprior : callable
        ``f(x, k)``. Per-row mode: ``x`` is the padded ``(D,)`` vector and
        ``k`` an int. With ``vectorized=True``: ``x`` is ``(n, D)`` and ``k``
        an ``(n,)`` integer array. Entries past ``k`` are NaN. ``lnprior`` is
        the joint prior over numbered slots including ``log p(k)``; for
        exchangeable components it is ``log p(k) + sum_{i<k} log pi(theta_i)``
        plus the shared prior, with no ``k!``. The likelihood is tempered and
        the prior is not.
    component_proposal : object
        Birth density for new components, with ``draw(rng, x, k) -> u``
        (``n_component`` values) and ``logpdf(u, x, k) -> float``, where
        ``(x, k)`` is always the smaller model's state. ``logpdf`` must be the
        normalized density of what ``draw`` returns and finite wherever the
        component prior is. Optional ``get_checkpoint_state`` /
        ``set_checkpoint_state`` and ``freeze_adaptation`` hooks are honoured
        and called once by the sampler. :class:`IndependentComponentProposal`
        wraps state-free functions.
    min_components : int, default 0
        Smallest ``k``. With ``min_components == max_components`` the built-in
        birth/death move is not registered.
    birth_death_weight : float, default 40
        Weight of the built-in birth/death move (about 30% of moves with the
        default ``am``/``scam``/``de`` weights); 0 disables it.
    component_redraw_weight : float, default 0
        Weight of ``component_redraw``, which replaces one component with a
        fresh draw from ``component_proposal`` at the same ``k``.
    component_periodic : dict, optional
        Periodic component parameters, ``{index within a component: period or
        (low, high)}``, applied to every slot.
    periodic : dict, optional
        Periodic parameters by index into the padded vector ``0 .. D - 1``
        (normally the shared ones). May not overlap ``component_periodic``.
    vectorized : bool, default False
        As in :class:`PTSampler`; selects the calling convention above.
    **kwargs
        Any other :class:`PTSampler` keyword (``ntemps``, ``outdir``,
        ``seed``, ``groups``, ``sample_cov``, ...). ``groups`` and
        ``sample_cov`` index the padded vector. ``ndim`` is set by the sampler
        and may not be passed.

    Attributes
    ----------
    layout : RJLayout
        The padded-row convention, also available to moves as
        ``chain_stats.layout``.
    birth_death : BirthDeath or None
        The built-in birth/death move, if registered.

    Notes
    -----
    Rows seen by the parallel-tempering engine have width ``D + 1`` with ``k``
    last, so the default temperature-ladder step ``1 + sqrt(2 / ndim)`` uses
    ``ndim = D + 1``; pass ``temp_step`` or ``max_temp`` to set it directly.

    The within-model moves are ``rj_am``, ``rj_scam`` and ``rj_de`` (weights
    ``am_weight``, ``scam_weight``, ``de_weight``), restricted to the active
    coordinates. Add more with :meth:`add_custom_jump`, and moves between
    models with :meth:`add_model_jump`.

    Components are exchangeable, so a slot does not follow one physical
    component through the run (label switching): summarize ``k``, the shared
    parameters and label-free quantities rather than per-slot values.
    """

    def __init__(
        self,
        *,
        n_shared: int,
        n_component: int,
        max_components: int,
        lnlike: Callable,
        lnprior: Callable,
        component_proposal: Any,
        min_components: int = 0,
        birth_death_weight: float = 40.0,
        component_redraw_weight: float = 0.0,
        component_periodic: Optional[PeriodicSpec] = None,
        periodic: Optional[PeriodicSpec] = None,
        vectorized: bool = False,
        **kwargs: Any,
    ) -> None:
        if "ndim" in kwargs:
            raise TypeError(
                "RJPTSampler sets ndim itself (n_shared + max_components * n_component, "
                "plus the k column); do not pass ndim"

        self.layout = RJLayout(n_shared, n_component, max_components, min_components)
        _check_component_proposal(component_proposal)
        for name, weight in (
            ("birth_death_weight", birth_death_weight),
            ("component_redraw_weight", component_redraw_weight),
        ):
            if not (math.isfinite(weight) and weight >= 0):
                raise ValueError(f"{name} must be a finite number >= 0, got {weight!r}")
        self.component_proposal = component_proposal
        self._wrapped_jumps: Dict[int, _WrappedJump] = {}
        self._model_jumps: List[_ModelJump] = []
        d = self.layout.ndim
        super().__init__(
            ndim=d + 1,

            lnprior=_RJCallable(lnprior, d, vectorized),
            periodic=_merge_periodic(self.layout, periodic, component_periodic),
            vectorized=vectorized,
            **kwargs,

            self.component_redraw = ComponentRedraw(self.layout, component_proposal)
            self.proposal_bundle.add_jump(self.component_redraw, component_redraw_weight)

    def _build_chain_stats(
        self,
        groups: Optional[list],
        sample_cov: Optional[np.ndarray],
        sample_mean: Optional[np.ndarray],
        buffer_size: int,
        buffer_thin: int,
    ) -> MultiChainStats:
        chain_stats: List[ChainStats] = [
            MaskedChainStats(
                self.layout.ndim,
                self.ptstate,
                ii,
                self.rngs[ii],
                groups=groups,
                sample_cov=sample_cov,
                sample_mean=sample_mean,
                buffer_size=buffer_size,
                buffer_thin=buffer_thin,
                layout=self.layout,
            )
            for ii in range(self.ntemps)
        ]
        return MultiChainStats(chain_stats)

    def _build_proposal_bundle(
        self, am_weight: float, scam_weight: float, de_weight: float, de_min_fill: int
    ) -> ProposalBundle:

        jumps: List[JumpProposals] = [
            _RJJumpProposals(cs) for cs in self.multi_chain_stats.chain_stats
        ]
        for jp in jumps:
            jp.add_jump(rj_am, am_weight)
            jp.add_jump(rj_scam, scam_weight)
            jp.add_jump(de_jump, de_weight)
        return ProposalBundle(jumps)

    def add_custom_jump(self, proposal: Any, weight: float) -> None:
        """Register a within-model move on every chain.

        ``proposal(chain_stats) -> (row, qxy)`` with ``row`` of shape
        ``(D + 1,)`` and ``row[-1]`` equal to the current ``k``. It must not
        change ``k`` or write to slots past ``k``; both are checked and raise
        ``ValueError`` naming the move.
        """
        wrapped = self._wrapped_jumps.get(id(proposal))
        if wrapped is None:
            wrapped = _CheckedWithinModelJump(proposal, self.layout)
            self._wrapped_jumps[id(proposal)] = wrapped
        elif not isinstance(wrapped, _CheckedWithinModelJump):
            raise ValueError(f"{wrapped.__name__!r} is already registered as a model jump")
        self.proposal_bundle.add_jump(wrapped, weight)

    def add_model_jump(self, move: Any, weight: float, log_jacobian: float = 0.0) -> None:
        """Register a move between models on every chain.

        ``move(chain_stats) -> (row, qxy)``, with ``row[-1]`` the new ``k``
        and ``qxy`` Green's ratio without the Jacobian:
        ``log[j(y->x) g'(u') / (j(x->y) g(u))]``, plus ``log|det J|`` only if
        it depends on the state. The sampler adds ``log_jacobian`` when ``k``
        increases and subtracts it when ``k`` decreases. Register a move and
        its reverse as one proposal, which computes ``j(y->x)`` itself.
        Returned rows are checked (valid ``k``, finite active values, NaN past
        ``k``); a violation raises ``ValueError`` naming the move.
        """
        log_jacobian = float(log_jacobian)
        if not math.isfinite(log_jacobian):
            raise ValueError(
                f"log_jacobian for model jump {_jump_name(move)!r} must be finite, "
                f"got {log_jacobian}"
            )
        wrapped = self._wrapped_jumps.get(id(move))
        if wrapped is None:
            wrapped = _ModelJump(move, self.layout, log_jacobian)
            self._wrapped_jumps[id(move)] = wrapped
            self._model_jumps.append(wrapped)
        elif isinstance(wrapped, _ModelJump):
            wrapped.log_jacobian = log_jacobian
        else:
            raise ValueError(f"{wrapped.__name__!r} is already registered as a within-model jump")
        self.proposal_bundle.add_jump(wrapped, weight)

    def _freeze_adaptive_proposals(self) -> None:
        super()._freeze_adaptive_proposals()
        freeze = getattr(self.component_proposal, "freeze_adaptation", None)
        if callable(freeze):
            freeze()

    def sample(
        self,
        initial_position: np.ndarray,
        num_iterations: int,
        thin: int = 1,
        initial_k: Any = None,
    ) -> None:
        """Run the sampler.

        Parameters
        ----------
        initial_position : np.ndarray
            Padded parameters without ``k``: ``(D,)`` for every temperature or
            ``(ntemps, D)``. Entries past ``initial_k`` are ignored (set to NaN).
        num_iterations : int
            Total iterations, including any already completed on resume.
        thin : int, default 1
            Save every ``thin``-th iteration.
        initial_k : int or sequence of int, optional
            Starting number of components, one value or one per temperature;
            defaults to ``min_components``.
        """
        layout = self.layout
        x0 = np.asarray(initial_position, dtype=float)
        if x0.ndim == 1 or (x0.ndim == 2 and x0.shape[0] == 1):
            x0 = np.broadcast_to(x0.reshape(1, -1), (self.ntemps, x0.shape[-1]))
        if x0.shape != (self.ntemps, layout.ndim):
            raise ValueError(
                f"initial_position must have shape ({layout.ndim},) or "
                f"({self.ntemps}, {layout.ndim}): the padded parameters without k; "
                f"got {np.shape(initial_position)}"
            )
        k0 = layout.min_components if initial_k is None else initial_k
        try:
            ks = np.broadcast_to(np.asarray(k0), (self.ntemps,))
        except ValueError:
            raise ValueError(
                f"initial_k must be one integer or {self.ntemps} of them, got {initial_k!r}"
            ) from None
        rows = np.stack([layout.make_row(x0[i], ks[i]) for i in range(self.ntemps)])
        super().sample(rows, num_iterations, thin=thin)
        if self.birth_death is not None and self.birth_death.rejected_deaths:
            warnings.warn(
                f"birth_death: {self.birth_death.rejected_deaths} death proposal(s) were "
                "rejected because component_proposal.logpdf returned -inf for the component "
                "being removed. The proposal must be finite wherever the component prior "
                "is; otherwise those deaths can never happen and the posterior on k is "
                "biased.",
                RuntimeWarning,
                stacklevel=2,
            )

    def load_chain(self) -> dict:
        """Load the saved chains.

        Returns the :meth:`PTSampler.load_chain` keys, with ``samples`` the
        NaN-padded parameters ``(ntemps, n, D)`` (no ``k`` column), plus
        ``k`` ``(ntemps, n)`` integers and the views ``shared``
        ``(ntemps, n, n_shared)`` and ``components``
        ``(ntemps, n, max_components, n_component)``.
        """
        chain = super().load_chain()
        rows = chain["samples"]
        d = self.layout.ndim
        samples = np.ascontiguousarray(rows[..., :d])
        chain["samples"] = samples
        chain["k"] = rows[..., d].astype(np.int64)
        chain["shared"] = self.layout.shared(samples)
        chain["components"] = self.layout.components(samples)
        return chain

    def _rj_settings(self) -> dict:
        return {
            "n_shared": self.layout.n_shared,
            "n_component": self.layout.n_component,
            "max_components": self.layout.max_components,
            "min_components": self.layout.min_components,
            "component_proposal": type(self.component_proposal).__name__,
            "model_jumps": [[j.__name__, j.log_jacobian] for j in self._model_jumps],
        }

    def _capture_checkpoint_state(self) -> Tuple[dict, dict]:
        arrays, meta = super()._capture_checkpoint_state()
        getter = getattr(self.component_proposal, "get_checkpoint_state", None)
        rj = self._rj_settings()

        meta["reversible_jump"] = rj

    def _restore_checkpoint_state(self, arrays: dict, meta: dict) -> None:

    def _verify_extra_metadata(self, meta: dict) -> None:
```

```python
LOG_SQRT_2PI = 0.5 * math.log(2 * math.pi)


def normal_logpdf(z):
    """Sum of standard-normal log densities."""
    z = np.asarray(z, dtype=float)
    return float(np.sum(-0.5 * z * z - LOG_SQRT_2PI))


def birth_probability(layout, k):
    if k >= layout.max_components:
        return 0.0
    if k <= layout.min_components:
        return 1.0
    return 0.5


class AffineBirthDeath:
    """Birth/death pair with theta = mu + sigma * u, u ~ N(0, I).

    Registered with add_model_jump(..., log_jacobian=sum(log sigma)): qxy here
    omits the Jacobian, which the sampler adds (birth) or subtracts (death).
    """

    __name__ = "affine_birth_death"

    def __init__(self, mu, sigma):
        self.mu = np.asarray(mu, dtype=float)
        self.sigma = np.asarray(sigma, dtype=float)

    def __call__(self, cs):
        layout, rng, x = cs.layout, cs.rng, cs.current_sample
        k = layout.k(x)
        b = birth_probability(layout, k)
        if rng.random() < b:
            j = int(rng.integers(0, k + 1))
            u = rng.standard_normal(layout.n_component)
            y = layout.insert(x, j, self.mu + self.sigma * u)
            d_next = 1.0 - birth_probability(layout, k + 1)
            return y, math.log(d_next) - math.log(b) - normal_logpdf(u)
        j = int(rng.integers(0, k))
        y, theta = layout.remove(x, j)
        u = (theta - self.mu) / self.sigma
        b_prev = birth_probability(layout, k - 1)
        return y, math.log(b_prev) - math.log(1.0 - b) + normal_logpdf(u)


def assert_rj_chains_identical(
    a, b, keys=("samples", "k", "lnlike", "lnprob", "accepted", "temperature")
):
    for key in keys:
        assert a[key].shape == b[key].shape, f"{key}: shape {a[key].shape} vs {b[key].shape}"
        assert np.array_equal(a[key], b[key], equal_nan=True), f"{key} differs"


def batch_mean_z(series, target, n_batches=40):
    """(mean - target) / batch-means standard error, on the last multiple of n_batches."""
    series = np.asarray(series, dtype=float)
    n = len(series) // n_batches * n_batches
    batches = series[len(series) - n :].reshape(n_batches, -1).mean(axis=1)
    se = batches.std(ddof=1) / math.sqrt(n_batches)
    return (batches.mean() - target) / max(se, 1e-12)
```

```python
def k_z_scores(ks, probs):
    """Batch-means z of each k indicator, for every k with probability >= 0.005."""
    return np.array(
        [batch_mean_z(ks == k, p) for k, p in enumerate(probs) if p >= 0.005], dtype=float
    )


class KillLastBirthDeath(BirthDeath):
    """Broken on purpose: always removes the last component."""

    __name__ = "kill_last"

    def _choose_death_slot(self, rng, k):

class NoSelectionRatioBirthDeath(BirthDeath):
    """Broken on purpose: drops log(d_{k+1} / b_k), which is not 0 at the k limits."""

    __name__ = "no_selection_ratio"

    def _selection_log_ratio(self, k):

# --- Prior only: lnlike = 0, truncated Poisson(2) on k, U(0, 1)^2 components -------------

PRIOR_K, PRIOR_P = 4, 2
POISSON = stats.poisson.pmf(np.arange(PRIOR_K + 1), 2.0)
POISSON = POISSON / POISSON.sum()
LOG_POISSON = np.log(POISSON)
_LOG_BETA_8_24 = math.lgamma(8) + math.lgamma(24) - math.lgamma(32)


def _zero_lnlike(x, k):
    return 0.0


def _poisson_lnprior(x, k):
    comps = x.reshape(PRIOR_K, PRIOR_P)[:k]
    if np.any((comps < 0) | (comps > 1)):
        return -np.inf
    return float(LOG_POISSON[k])


def _uniform_draw(rng):
    return rng.random(PRIOR_P)


def _uniform_logpdf(u):
    u = np.asarray(u)
    return 0.0 if np.all((u >= 0) & (u <= 1)) else -np.inf


def _mixed_draw(rng):
    return rng.random(PRIOR_P) if rng.random() < 0.5 else rng.beta(8.0, 24.0, PRIOR_P)


def _mixed_logpdf(u):
    u = np.asarray(u, dtype=float)
    if np.any((u < 0) | (u > 1)):
        return -np.inf
    with np.errstate(divide="ignore"):
        log_beta = float(np.sum(7.0 * np.log(u) + 23.0 * np.log1p(-u) - _LOG_BETA_8_24))
    return math.log(0.5 + 0.5 * math.exp(log_beta))


PRIOR_BIRTHS = IndependentComponentProposal(_uniform_draw, _uniform_logpdf)
MIXED_BIRTHS = IndependentComponentProposal(_mixed_draw, _mixed_logpdf)


class CentredBeta:
    """Half uniform, half a Beta centred on the existing components' mean (state-dependent)."""

    def __init__(self, layout):
        self.layout = layout

    def _shape(self, x, k):
        comps = self.layout.components(x)[:k]
        centre = np.clip(comps.mean(axis=0), 0.1, 0.9) if k else np.full(PRIOR_P, 0.5)
        return 20.0 * centre, 20.0 * (1.0 - centre)

    def draw(self, rng, x, k):
        if rng.random() < 0.5:
            return rng.random(PRIOR_P)
        a, b = self._shape(x, k)
        return rng.beta(a, b)

    def logpdf(self, u, x, k):
        u = np.asarray(u, dtype=float)
        if np.any((u < 0) | (u > 1)):
            return -np.inf
        a, b = self._shape(x, k)
        return math.log(0.5 + 0.5 * math.exp(float(np.sum(stats.beta.logpdf(u, a, b)))))

def _component_z(comps):
    """z of (count below 0.25) and (sum - 0.5 per value), both 0 under U(0, 1)."""
    active = ~np.isnan(comps[..., 0])
    n_values = PRIOR_P * active.sum(axis=1)
    below = np.where(active[..., None], comps < 0.25, False).sum(axis=(1, 2)) - 0.25 * n_values
    centred = np.where(active[..., None], comps, 0.0).sum(axis=(1, 2)) - 0.5 * n_values

# --- Analytic posterior on k: y_n ~ N(sum_{i<k} a_i, 1), a_i ~ N(0, 1), uniform k ----------

def _log_evidence(k):
    """log N(Y; 0, I + k 11^T) up to a k-independent constant (Sherman-Morrison)."""
    c, n = float(k), len(Y)
    return -0.5 * (math.log1p(n * c) + Y @ Y - c * Y.sum() ** 2 / (1.0 + n * c))


_LOG_Z = np.array([_log_evidence(k) for k in range(GAUSS_K + 1)])
```

````markdown
# Reversible jump: a variable number of components

`RJPTSampler` samples models made of a variable number `k` of copies of one
component type (sinusoids, pulses, galactic binaries, glitches, spline knots),
plus optional *shared* parameters that every model has, such as a noise level.
The state is `(k, θ_k)`, where `θ_k` holds the shared parameters and `k`
components of `p` parameters each. Moves that add or remove a component change
the number of parameters and are accepted with Green's reversible-jump ratio.

`RJPTSampler` is a `PTSampler`: tempering, the adaptive proposals, vectorized,
threaded and JAX likelihoods, and checkpoint/resume all work as described in
the rest of this guide. This page covers what is different.

## How the state is stored

Every stored row has the same width. With `K = max_components`,
`p = n_component` and `D = n_shared + K·p`:

| Columns | Content |
|---|---|
| `0` to `n_shared − 1` | shared parameters |
| `n_shared + i·p` to `n_shared + (i + 1)·p − 1` | component slot `i`, for `i = 0, …, K − 1` |
| `D` | `k` |

Slots `k` to `K − 1` hold NaN. Your likelihood and prior receive the `D`
parameter columns as `x` and the model index separately as `k`. The padding is
storage only: inactive slots are never sampled and carry no density.

## Quickstart: how many pulses?

Data with two Gaussian pulses in white noise, fitted with up to five pulses of
two parameters each (amplitude, centre). There are no shared parameters.

```python
import numpy as np

from impulse import IndependentComponentProposal, RJPTSampler

K, P = 5, 2  # up to 5 pulses, each (amplitude, centre)
WIDTH, SIGMA = 0.3, 0.1
LOW, HIGH = np.array([0.0, 0.0]), np.array([2.0, 10.0])
LOG_VOLUME = np.log(np.prod(HIGH - LOW))

rng = np.random.default_rng(0)
t = np.linspace(0.0, 10.0, 200)


def pulses(comps):
    return sum(a * np.exp(-0.5 * ((t - c) / WIDTH) ** 2) for a, c in comps)


data = pulses([(1.0, 3.0), (0.7, 6.5)]) + SIGMA * rng.standard_normal(t.size)


def lnlike(x, k):
    comps = x.reshape(K, P)[:k]  # x has shape (K * P,); slots past k are NaN
    r = data - pulses(comps)
    return -0.5 * np.dot(r, r) / SIGMA**2


def lnprior(x, k):
    comps = x.reshape(K, P)[:k]
    if np.any((comps < LOW) | (comps > HIGH)):
        return -np.inf
    return -k * LOG_VOLUME  # uniform p(k) is a constant; no k! term


births = IndependentComponentProposal(
    draw=lambda rng: rng.uniform(LOW, HIGH),
    logpdf=lambda u: -LOG_VOLUME if np.all((u >= LOW) & (u <= HIGH)) else -np.inf,
)

sampler = RJPTSampler(
    n_shared=0,
    n_component=P,
    max_components=K,
    lnlike=lnlike,
    lnprior=lnprior,
    component_proposal=births,
    ntemps=4,
    seed=1,
    outdir="rj_chains",
    verbose=False,
)
sampler.sample(np.zeros(K * P), num_iterations=5000, initial_k=0)

chain = sampler.load_chain()
ks = chain["k"][0, 1000:]  # cold chain after burn-in
print("p(k):", (np.bincount(ks, minlength=K + 1) / ks.size).round(3))
```

`births` is the *component proposal*: the density that birth moves draw new
components from. Here it is the component prior.

### The prior is over numbered slots

`lnprior(x, k)` is the joint density of `k` and the parameters in slots `0` to
`k − 1`. For interchangeable components it is

$$\log p(k) + \sum_{i<k} \log \pi(\theta_i) \;\; (+ \text{the shared prior}),$$

with **no** `k!` term: every ordering of the same set of components is a
separate state of the chain, and all of them are sampled. If you impose an
ordering instead (say, increasing centre), the prior gains `+ log k!` and a
birth is valid at only one insert position; relabelling after sampling, shown
below, is simpler.

## Vectorized likelihoods

With `vectorized=True`, `x` is `(batch, D)` and `k` is `(batch,)`. Mask the
inactive slots with `np.where` before using them: their values are NaN, and
`0 * NaN` is NaN.

```python
def lnlike_vectorized(x, k):
    comps = x.reshape(-1, K, P)  # (batch, K, P)
    active = np.arange(K)[None, :] < k[:, None]  # (batch, K)
    amplitude = np.where(active, comps[..., 0], 0.0)  # inactive pulses get amplitude 0
    centre = np.where(active, comps[..., 1], 0.0)
    shapes = np.exp(-0.5 * ((t - centre[..., None]) / WIDTH) ** 2)  # (batch, K, n_t)
    r = data - np.sum(amplitude[..., None] * shapes, axis=1)
    return -0.5 * np.sum(r * r, axis=1) / SIGMA**2

    active = np.arange(K)[None, :] < k[:, None]
    inside = np.where(active[..., None], (comps >= LOW) & (comps <= HIGH), True).all(axis=(1, 2))
    return np.where(inside, -k * LOG_VOLUME, -np.inf)


check_k = np.array([0, 1, 2, 5])
check_x = np.full((4, K * P), np.nan)
for row, kk in zip(check_x, check_k):

assert np.allclose(

## Component proposals

Birth/death (reported as `birth` and `death`; weight `birth_death_weight`,
default 40) and the optional `component_redraw` move draw new components from
the `component_proposal`: an object with

- `draw(rng, x, k) -> u`: one component, shape `(p,)`;
- `logpdf(u, x, k) -> float`: the **normalized** log density of exactly what
  `draw` returns.

`(x, k)` is always the state of the *smaller* model: the current state for a
birth, and the state after removing the component for a death. A proposal that
depends on it (for example, one that avoids existing components) therefore
stays correct: the death evaluates `logpdf` at the same smaller state the
matching birth drew from.

Two requirements are yours to meet:

- **Coverage.** `logpdf` must be finite wherever the component prior is. A
  death whose component has `logpdf = −inf` cannot be reversed and is
  rejected; a `RuntimeWarning` at the end of the run says how many were.
  Mixing a sharp density with the prior, as below, guarantees coverage.
- **A fixed density.** A density that changes during the run must stop
  changing at `num_adapt`, by implementing `freeze_adaptation()`.

`IndependentComponentProposal(draw, logpdf)` wraps state-free functions
`draw(rng)` and `logpdf(u)`, as in the quickstart. The prior is always a valid
birth density, but a poor one when the likelihood is sharp: most births land
where the data rule a component out. A density built from the data does
better. For galactic binaries that is an F-statistic map; for these pulses, a
matched filter over the centre:

```python
edges = np.linspace(LOW[1], HIGH[1], 101)  # 100 centre cells of width 0.1
centres = 0.5 * (edges[:-1] + edges[1:])
templates = np.exp(-0.5 * ((t[None, :] - centres[:, None]) / WIDTH) ** 2)
matched = np.maximum(templates @ data, 0.0) ** 2  # large where a pulse fits the data


class GriddedProposal:
    """Centre from a gridded density mixed with the prior; amplitude from the prior."""

    def __init__(self, edges, weights, mix=0.5):
        self.edges = np.asarray(edges, dtype=float)
        widths = np.diff(self.edges)
        weights = np.asarray(weights, dtype=float)
        self.cell_prob = mix * weights / weights.sum() + (1 - mix) * widths / widths.sum()
        self.log_density = np.log(self.cell_prob / widths)

    def draw(self, rng, x, k):
        cell = rng.choice(self.cell_prob.size, p=self.cell_prob)
        centre = rng.uniform(self.edges[cell], self.edges[cell + 1])
        return np.array([rng.uniform(LOW[0], HIGH[0]), centre])

    def logpdf(self, u, x, k):
        amplitude, centre = u
        if not (LOW[0] <= amplitude <= HIGH[0] and self.edges[0] <= centre <= self.edges[-1]):
            return -np.inf
        cell = min(np.searchsorted(self.edges, centre, side="right") - 1, self.cell_prob.size - 1)
        return self.log_density[cell] - np.log(HIGH[0] - LOW[0])


gridded = RJPTSampler(
    n_shared=0,
    n_component=P,
    max_components=K,
    lnlike=lnlike,
    lnprior=lnprior,
    component_proposal=GriddedProposal(edges, matched),
    ntemps=4,
    seed=1,
    outdir="rj_chains_gridded",
    verbose=False,
)
gridded.sample(np.zeros(K * P), num_iterations=5000, initial_k=0)

for name, run in [("prior births", sampler), ("matched-filter births", gridded)]:
    rates = run.proposal_acceptance_rates()
    print(f"{name}: birth {rates['birth']['rate']:.3f}, death {rates['death']['rate']:.3f}")
```

## Custom moves

### Within a model: `add_custom_jump`

A within-model move has the `PTSampler` signature (see
{doc}`custom-proposals`), `move(chain_stats) -> (row, qxy)`, with two
differences: `chain_stats.current_sample` is the full row `(D + 1,)` with `k`
last, and the returned row must keep the same `k` and NaN in the same slots
(the sampler raises `ValueError` naming the move otherwise).
`chain_stats.layout` is an {class}`~impulse.RJLayout`, which knows where each
slot is:

```python
class NudgeCentre:
    """Shift one random component's centre by N(0, 0.05^2): symmetric, so qxy = 0."""

    __name__ = "nudge_centre"

    def __call__(self, cs):
        layout, x = cs.layout, cs.current_sample
        k = layout.k(x)
        if k == 0:
            return x.copy(), 0.0
        y = x.copy()
        centre = layout.slot(int(cs.rng.integers(k))).start + 1  # parameter 1 of that slot
        y[centre] += 0.05 * cs.rng.standard_normal()
        return y, 0.0
```

### Between models: `add_model_jump`

A move that changes `k` has the same signature and returns the new row, whose
last entry is the new `k`. Register a move **and its reverse as one
proposal**: the move picks a direction itself, and its `qxy` includes the
probability of picking the reverse.

For a move from `x` to `y` that draws random numbers `u` with density `g`,
whose reverse draws `u'` with density `g'`,

$$\mathrm{qxy} = \log \frac{j(y \to x)\, g'(u')}{j(x \to y)\, g(u)}
+ \log \left| \det \frac{\partial (y, u')}{\partial (x, u)} \right|,$$

where `j` is the probability of choosing that direction. When the Jacobian is
the same constant for every birth (as when a birth maps `u` to the new
component by a fixed affine map), pass its log as `log_jacobian` and leave it
out of `qxy`: the sampler adds it when `k` grows and subtracts it when `k`
shrinks.

Here a birth draws the new pulse as `θ = μ + σ·u` with `u ~ N(0, I)`, so
`log_jacobian = Σ log σ`. The position factors `1/(k + 1)` (where to insert,
which to remove) cancel between a move and its reverse:

```python
class AffineBirthDeath:
    """Birth: theta = mu + sigma * u, u ~ N(0, I), at a random position. Death: the reverse."""

    __name__ = "affine_birth_death"

    def __init__(self, mu, sigma):
        self.mu, self.sigma = np.asarray(mu, dtype=float), np.asarray(sigma, dtype=float)

    @staticmethod
    def birth_probability(layout, k):
        if k >= layout.max_components:
            return 0.0
        return 1.0 if k <= layout.min_components else 0.5

    @staticmethod
    def log_normal(u):
        return float(np.sum(-0.5 * u * u - 0.5 * np.log(2 * np.pi)))

    def __call__(self, cs):
        layout, rng, x = cs.layout, cs.rng, cs.current_sample
        k = layout.k(x)
        b = self.birth_probability(layout, k)
        if rng.random() < b:  # birth, at one of k + 1 positions
            u = rng.standard_normal(layout.n_component)
            y = layout.insert(x, int(rng.integers(k + 1)), self.mu + self.sigma * u)
            d_next = 1.0 - self.birth_probability(layout, k + 1)
            return y, np.log(d_next) - np.log(b) - self.log_normal(u)
        y, theta = layout.remove(x, int(rng.integers(k)))  # death, of one of k
        u = (theta - self.mu) / self.sigma
        b_prev = self.birth_probability(layout, k - 1)
        return y, np.log(b_prev) - np.log(1.0 - b) + self.log_normal(u)


SIGMA_BIRTH = np.array([0.5, 2.5])
custom = RJPTSampler(
    n_shared=0,
    n_component=P,
    max_components=K,
    lnlike=lnlike,
    lnprior=lnprior,
    component_proposal=births,
    birth_death_weight=0,  # the built-in birth/death is replaced by the jump below
    ntemps=4,
    seed=2,
    outdir="rj_chains_custom",
    verbose=False,
)
custom.add_model_jump(
    AffineBirthDeath(mu=[1.0, 5.0], sigma=SIGMA_BIRTH),
    weight=40,
    log_jacobian=float(np.sum(np.log(SIGMA_BIRTH))),
)
custom.add_custom_jump(NudgeCentre(), weight=10)
custom.sample(np.zeros(K * P), num_iterations=2000, initial_k=0)
print(sorted(custom.proposal_acceptance_rates()))
```

The sampler checks every model jump's result (`k` within the limits, finite
values before slot `k`, NaN after it) and raises `ValueError` naming the jump
otherwise.

### Redrawing a component

`component_redraw_weight` (default 0) adds `component_redraw`: replace one
random component with a fresh draw from the component proposal, keeping `k`.
With a good component proposal it lets a component jump straight to another
mode, which local moves can't.

## Periodic parameters

`component_periodic={j: period}` marks parameter `j` of every component as
periodic: for components `(log10 A, f, φ)`, `component_periodic={2: 2 * np.pi}`
wraps every phase. `periodic` takes indices into the padded parameter vector
and is for shared parameters; the two may not overlap.

## Reading the chains

`load_chain()` returns the `PTSampler` keys, with:

- `samples`: `(ntemps, n, D)`, NaN past each row's `k`;
- `k`: `(ntemps, n)` integers;
- `shared`: `(ntemps, n, n_shared)` and `components`: `(ntemps, n, K, p)`,
  views of `samples`.

### Label switching

Slot 0 in one sample need not be the same pulse as slot 0 in the next: births
insert at random positions, and nothing in the posterior tells the slots
apart. Per-slot means, traces and R-hat are therefore meaningless. Use
summaries that don't depend on the labels, such as the distribution of all
active centres, or relabel each sample (here, by sorting on the centre) before
summarizing:

```python
comps = chain["components"][0, 1000:]  # (n, K, P), NaN past k
centre_values = comps[..., 1][~np.isnan(comps[..., 1])]  # every active centre, any slot
near = (np.abs(centre_values - 3.0) < 0.2) | (np.abs(centre_values - 6.5) < 0.2)
print("share of centres near a true pulse:", near.mean().round(3))

two = comps[ks == 2][:, :2]  # samples with k = 2: (m, 2, P)
order = np.argsort(two[..., 1], axis=1)  # sort each sample's pulses by centre
relabelled = np.take_along_axis(two, order[..., None], axis=1)
print("mean (amplitude, centre) per pulse:", relabelled.mean(axis=0).round(2).tolist())
```

## Checkpoints and resume

Resume works as for `PTSampler` (see {doc}`checkpointing`): rebuild the
sampler the same way, with the same constructor arguments, the same
`add_custom_jump` and `add_model_jump` calls in the same order, and a component
proposal of the same class, then pass `resume=True`. On top of the `PTSampler`
checks, a changed `n_shared`, `n_component`, `max_components`,
`min_components`, component proposal class, or model jump `log_jacobian`
raises `CheckpointMismatchError`.

The sampler cannot tell whether a component proposal was rebuilt from
different data or settings. A proposal can guard against that by returning a
fingerprint from `get_checkpoint_state()` and comparing it in
`set_checkpoint_state(state)`:

```{code-block} python
import hashlib


class CheckedGriddedProposal(GriddedProposal):
    def get_checkpoint_state(self):
        return {"map": hashlib.sha256(self.log_density.tobytes()).hexdigest()}

    def set_checkpoint_state(self, state):
        if state["map"] != self.get_checkpoint_state()["map"]:
            raise ValueError("the birth map differs from the checkpointed run")
```
````

````markdown
`RJPTSampler` samples models with a variable number `k` of copies of one

pulse_data += 0.1 * np.random.default_rng(0).standard_normal(pulse_t.size)

    comps = x.reshape(4, 2)[:k]
````

- **Task 3 (after code review):** `MaskedChainStats.active_block(g, k)` factors a per-model covariance `Σ_k = (n_k·Σ̂_k + n0·P_k)/(n_k + n0)` (`Σ̂_k` from the buffered rows whose model is exactly `k`, `P_k` the pooled clipped block, `n0 = max(min_pair_rows, 2·d_k)`; `P_k` alone when `n_k < 2`) instead of the pooled clipped matrix, which stays as `sample_cov`. Caches are cleared on every buffer update, and the ridge follows the checkpointed fallback covariance. Inactive slots are forced to NaN before storage, windows with an invalid `k` are skipped, and the fallback covariance/mean are checkpointed. Signature and return tuple unchanged, so later tasks are unaffected. The spec's "Within-model moves" section was updated to match.
- **Task 4 (after code review):** `RJDEProposal` redraws a row pair whose masked difference is zero on every active coordinate (up to 16 draws, then the current state); symmetry and x-independence are pinned by tests. Spec updated.
- **For Task 10 (docs):** with no active coordinates (e.g. `n_shared = 0` at `k = 0`) the within-model moves return the current state, which costs a likelihood call and counts as accepted, so within-model acceptance at low `k` reads high. Mention this next to the acceptance-report text.
- **Task 5 (after code review):** the wrappers read the old state before calling a user move and reject a returned row that shares memory with `current_sample`; component proposals receive read-only views; `BirthDeath` rejects `min_components == max_components`; `draw` output must have shape `(n_component,)`; the within-model wrapper also requires finite active values.
- **For Task 6:** `add_custom_jump` / `add_model_jump` must reject a move whose name is `birth` or `death` (they would overwrite the built-in birth/death entries in `proposal_acceptance_rates()`). A `BirthDeath` subclass registered through `add_model_jump` (as Task 8 does) reports unsplit under its own `__name__`; that is intended.
- **Task 6 (after code review):** births and component redraws now raise if a draw puts a periodic component coordinate outside its declared interval (closed check `low <= u <= high`, because `np.mod` can return exactly `high`), and a model jump's returned row must have its active periodic coordinates inside their intervals. Reason: the engine wraps the stored row, so a `logpdf` evaluated on an unwrapped draw is the density of the wrong value; the review measured p(k=0) = 0.017 against an analytic 0.059 with a Gaussian on a phase. Also: moves see a read-only `current_sample` (`MaskedChainStats.update_sample`); the `rejected_deaths` warning reports the count for this `sample()` call (running total in parentheses); component-proposal state is checked for JSON serializability when it is captured; `add_custom_jump`/`add_model_jump` validate weights; `sample_mean` shape is checked.
- **For Task 9 (GB example) and Task 10 (docs):** state the periodic rule wherever a component proposal or model jump is described. A draw must lie inside the declared periodic interval, and `logpdf`/`qxy` must be for that value: if the user starts from a distribution on the real line (e.g. an F-statistic or Fisher-jitter proposal on phase or polarization), wrap with `np.mod` and use the wrapped density. A draw on a different interval (e.g. `(-π, π)`) needs that interval declared in `component_periodic`. Also say `current_sample` is read-only.
